Install

Three ways in. Use whichever fits how you work.

Download a binary

  • macOS, Apple silicon
  • macOS, Intel
  • Windows
  • Linux, x64
  • Linux, ARM64

On macOS and Linux, make it executable first. On macOS, also clear the download quarantine, because the binary isn't notarized:

chmod +x mydy-darwin-arm64
xattr -d com.apple.quarantine mydy-darwin-arm64
./mydy-darwin-arm64

Or run it from source

With Bun 1.3 or newer:

git clone https://github.com/Deeptanshuu/mydy-lms-helper.git
cd mydy-lms-helper
bun install
bun run tui

Signing in

Sign in on the first screen and tick Remember me to keep the login in your system keychain. Or set MYDY_USERNAME and MYDY_PASSWORD in the environment or a .env file.

Icons use a Nerd Font. If you see empty boxes, run with --no-nerd-font for plain symbols.

Plug your AI assistant into your courses

The MCP server lets Claude Code, Claude Desktop or any other MCP client read your courses, attendance, assignments, grades and announcements, and download files.

git clone https://github.com/Deeptanshuu/mydy-lms-helper.git
cd mydy-lms-helper
python3 -m venv .venv
.venv/bin/pip install -r mcp/requirements.txt

Then add it to Claude Code:

claude mcp add mydy-lms \
  -e MYDY_USERNAME=your_email@dypatil.edu \
  -e MYDY_PASSWORD=your_password \
  -- "$PWD/.venv/bin/python" "$PWD/mcp/mcp_server.py"

Download files from the browser

The Chrome extension uses your logged-in MyDy tab to download course files, grouped by course. No install beyond Chrome.

  1. Download the latest ext-v* zip from Releases and extract it.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and pick the extracted folder.
  4. Open mydy.dypatil.edu, click the extension icon, choose courses and download.

How it works

your data

Your email and password are only ever sent to mydy.dypatil.edu, over HTTPS. A saved login goes to your system keychain, and the cache and downloads stay on your computer. There are no servers of ours and no analytics.
